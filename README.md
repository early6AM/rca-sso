# rca_sso — вход в LMS через Telegram

Приложение для Frappe Learning (school.rca.yachts). Задача — дать ученице
входить в личный кабинет без пароля, не заводя второй аккаунт.

Ключ аккаунта — **почта**. Telegram — привязанный способ входа, а не
идентификатор пользователя: у аккаунта остаётся и пароль, и Telegram, и
одноразовая ссылка.

## Три пути входа

| Путь | Как выглядит |
|---|---|
| Почта и пароль | штатная регистрация Frappe |
| Код из 6 цифр | сайт показывает код → ученица отправляет его боту → браузер входит сам |
| Одноразовая ссылка | бот выдаёт ссылку на 15 минут — для тёплых лидов из воронки |

## Поток с кодом

1. `start` — браузер получает код (для человека) и токен опроса (для себя).
2. `confirm` — бот присылает код; приложение находит заявку, привязывает
   Telegram и помечает вход подтверждённым.
3. `poll` — браузер видит подтверждение и логинится **в своём же запросе**,
   поэтому cookie сессии уезжает тому, кто её ждал.

Код живёт 10 минут и срабатывает один раз. Токен опроса никому не
показывается — по нему подобрать чужой вход нельзя.

## Привязка

Страница `/telegram-bind` (только для вошедших): берём код, отправляем боту,
Telegram привязывается к текущему аккаунту. Если этот Telegram уже привязан
к другому аккаунту — отказ.

## Защита

- Эндпоинты бота открыты гостю, поэтому подписываются HMAC-SHA256 общим
  секретом `rca_sso_secret` из конфига сайта (`X-SSO-Signature`).
- `rca_sso_secret` и `rca_sso_bot_username` задаются через
  `bench --site <site> set-config`.
- Ограничение попыток: не больше 30 незавершённых входов с одного IP в час.
- Вход по коду **не** привязывается к существующему аккаунту с чужой почтой —
  иначе по одному коду можно было бы угнать аккаунт. В таком случае ученице
  предлагается войти по почте и привязать Telegram в кабинете.
- В боте почта показывается частично (`an***@mail.ru`).

## Настройка

```bash
bench --site school.rca.yachts set-config rca_sso_secret "<секрет>"
bench --site school.rca.yachts set-config rca_sso_bot_username "rca_school_bot"
bench --site school.rca.yachts clear-cache
```

## Зависимости

Telegram-бот входа: `~/projects/rca-school-bot` (`@rca_school_bot`).
Секрет должен совпадать в конфиге сайта и в `.env` бота.
